01 · Principles and tokens

Calm chrome, the artwork brings the colour

Every swatch below is read live from the CSS variables, so the contrast ratios follow the theme you pick in the toolbar. Captions are token name · light / dark value.

  1. Chrome is achromatic; artwork supplies colourViolet only on the stage's one primary, the focus ring, the brand mark and selected states. Stage colour lives in 6 px dots and low-saturation badge pairs, never in column backgrounds or panel borders.
  2. Three tiers of surface and text, one token setcanvas / surface-1 / 2 / 3 and fg-1 / 2 / 3 as variables for both themes. Hover is one ladder step; depth is a hairline in dark and a level-0 shadow in light.
  3. Type is tiered, not big13 px/500 chrome, 14 px body, 11–12 px meta in tabular figures. Bricolage Grotesque only at 18 px and above; weights capped at 600; sentence case everywhere.
  4. Motion means work is happening, inside the thing being worked onOne signature per long wait (DEVELOP / INSPECT / FINISH), one landing gesture (SETTLE + one ring pulse), 200 ms entrances, 150 ms exits. Reduced motion keeps fades and drops loops.
  5. Facts before prose, one obvious next stepPrice and time on the control before the click, a mono spec row on results, one primary per screen, empty states that are the call to action.
